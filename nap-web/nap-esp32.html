Nạp firmware ESP32 qua web

Cắm bo ESP32 bằng cáp USB rồi bấm nạp thẳng trên trình duyệt — khỏi cần Arduino IDE. Dùng để nạp máy mới ở xưởng.

Trình duyệt này không hỗ trợ Web Serial — mở bằng Chrome/Edge trên máy tính. Trang phải mở qua HTTPS mới nạp được.

Các bước cắm máy

  1. Cắm bo ESP32 vào máy tính bằng cáp USB dữ liệu.
  2. Bấm ⚡ Nạp firmware, cửa sổ hiện lên chọn đúng cổng COM của bo (thường tên CP2102 / CH340 / USB-Serial).
  3. Chờ thanh chạy tới 100% rồi Reset — máy tự khởi động firmware mới.
  4. Với ghế: nạp xong cắm vào máy, ghế hiện trong “chờ gán” trên web để đặt mã.
Máy không hiện cổng COM?

Thiếu driver USB-UART. Cài driver CP2102 (Silicon Labs) hoặc CH340 tuỳ chip trên bo rồi cắm lại. Đổi sang cáp USB khác (nhiều cáp chỉ có 2 dây sạc, không truyền dữ liệu).

Nạp báo lỗi / kẹt giữa chừng?

Giữ nút BOOT (IO0) trên bo lúc bắt đầu nạp rồi thả khi thanh bắt đầu chạy. Đóng các phần mềm đang chiếm cổng COM (Arduino IDE, PuTTY). Thử lại — Update an toàn: nạp dở thì bo giữ firmware cũ, không hỏng.

Người quản trị: đặt file firmware ở đâu?

Trang này đọc firmware/<loại>/manifest.json. Sinh file *-merged.bin bằng esptool.py --chip esp32 merge_bin rồi đặt cạnh manifest. Xem README-nap-web.txt đi kèm.
