⚠️ ĐỪNG BỎ FILE VÀO THƯ MỤC NÀY NỮA
====================================

Chỗ đúng nay là:      wp-content/uploads/vhcc-mat/

VÌ SAO ĐỔI: cài đè plugin bằng file .zip thì WordPress XOÁ SẠCH thư mục plugin
cũ rồi giải nén bản mới đè lên — bảy megabyte vừa tải bay theo, và lần cập nhật
nào cũng bay lại. Thư mục uploads/ thì WordPress không đụng tới.

Thư mục này vẫn còn được ĐỌC (ai đã kịp bỏ file vào đây thì chưa phải làm lại),
nhưng lần cập nhật plugin tới là mất. Vào wp-admin → Chấm Công → Cài đặt, khối
"Đối chiếu khuôn mặt" sẽ có nút "⇢ Dời sang chỗ an toàn" — bấm một cái là xong,
nó chép qua chứ không tải lại.


CÁCH NHANH NHẤT: ĐỂ MÁY CHỦ TỰ TẢI
===================================
wp-admin → Chấm Công → Cài đặt → khối "Đối chiếu khuôn mặt" → nút
"⬇ Để máy chủ tự tải về". Bấm vài lần (nó tải từng đợt vì hosting cắt mỗi lượt
ở khoảng 30 giây) cho tới khi báo "✔ Thư viện đã sẵn sàng".

Chỉ khi hosting chặn máy chủ ra internet mới cần làm tay theo hướng dẫn dưới.


LÀM TAY: 8 FILE, BỎ VÀO wp-content/uploads/vhcc-mat/
=====================================================


CẦN 8 FILE
----------
Từ kho mã nguồn mở face-api.js trên GitHub:

    https://github.com/justadudewhohacks/face-api.js

  1. face-api.min.js                                  (thư mục dist/)

  Bảy file còn lại nằm trong thư mục weights/ :

  2. tiny_face_detector_model-weights_manifest.json
  3. tiny_face_detector_model-shard1
  4. face_landmark_68_tiny_model-weights_manifest.json
  5. face_landmark_68_tiny_model-shard1
  6. face_recognition_model-weights_manifest.json
  7. face_recognition_model-shard1
  8. face_recognition_model-shard2

Tổng cộng khoảng 7 MB. Nhân viên tải một lần rồi trình duyệt nhớ, những lần
sau không tải lại.


CÁCH TẢI
--------
Cách gọn nhất: vào trang GitHub ở trên → nút "Code" → "Download ZIP" → giải
nén → lấy đúng 8 file kể trên → tải lên hosting bằng File Manager của cPanel
(hoặc FTP) vào thư mục này.

Đường dẫn trên hosting:
    wp-content/uploads/vhcc-mat/

Thư mục chưa có thì tự tạo. Cập nhật plugin KHÔNG xoá thư mục này.


⚠️ VÌ SAO KHÔNG GỌI THẲNG TỪ INTERNET (CDN)
-------------------------------------------
  · Trang chấm công không phụ thuộc một địa chỉ ngoài mà mình không kiểm soát.
    CDN đổi đường dẫn hay nhà mạng chặn là cả tính năng chết mà không có gì báo.
  · Model 7 MB tải từ chính hosting của mình thì tốc độ do mình quyết.
  · Không gửi thông tin lượt truy cập của nhân viên sang máy chủ bên thứ ba.
